# Smart Stress Detection in Office Environment Using Machine Learning

## Project Overview
This project predicts the stress level of office employees based on daily behavioral factors such as working hours, sleep hours, task pressure, mood level, break frequency, and screen time.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Machine Learning
- Decision Tree Classifier

## Input Parameters
- Working Hours
- Sleep Hours
- Task Pressure
- Mood Level
- Break Frequency
- Screen Time

## Output
The system predicts:
- Low Stress
- Medium Stress
- High Stress

## Workflow
1. Collect employee behavioral dataset
2. Preprocess the dataset
3. Train machine learning model
4. Test prediction accuracy
5. Predict employee stress level

## Future Enhancement
This project can be integrated with wearable devices and real-time office monitoring systems.
